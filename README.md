# Модуль кросс-модельного семантического выравнивания схем данных

Данный программный комплекс разработан в рамках НИР по теме **«Разработка алгоритма извлечения семантических отношений из описаний полей таблиц»** для мультимодальной СУБД.

## Назначение проекта
Прототип извлекает скрытые семантические связи (тождества, ссылки, дубликаты) между элементами различных моделей данных (реляционной, документной, графовой), используя плотные векторные эмбеддинги текстовых описаний и NLP-предобработку.

## Инструкция по сборке и запуску

### Шаг 1: Подготовка виртуального окружения
Рекомендуется использовать изолированное окружение `venv`, которое уже инициализировано в корне проекта. Из корневой директории выполните команду для его активации:

*   **Для Linux / macOS:**
    ```bash
    source .venv/bin/activate
    ```
*   **Для Windows (Command Prompt):**
    ```cmd
    .venv\Scripts\activate.bat
    ```
*   **Для Windows (PowerShell):**
    ```powershell
    .venv\Scripts\Activate.ps1
    ```

### Шаг 2: Установка зависимостей
Установите базовые Python-пакеты из файла конфигурации:
```bash
pip install -r requirements.txt
```

### Шаг 3: Загрузка лингвистической языковой модели
Для токенизации и лемматизации англоязычных описаний полей необходимо загрузить легковесную NLP-модель от библиотеки `spaCy`:
```bash
python -m spacy download en_core_web_sm
```

### Шаг 4: Запуск приложения
Запустите главный исполняемый файл пайплайна:
```bash
python main.py
```

## Структура модулей проекта
*   `data_parse.py` — модуль-унификатор (`MetadataUnifier`). Имитирует коннекторы к СУБД, преобразуя сырые системные метаданные (SQL tables, JSON Schema, Cypher) в плоский DataFrame.
*   `semantic_matcher.py` — ядро алгоритма (`RealWorldSemanticMatcher`). Выполняет очистку текста, векторизацию через предобученную модель `all-MiniLM-L6-v2` и вычисление косинусного сходства.
*   `main.py` — точка входа, координирующая сквозной процесс (ETL метаданных -> анализ -> вывод результатов).
